# Hive — Student Housing & Roommate Finder

Hive is a web-based boarding house, dormitory, and roommate finder platform built for PUP students (**Seekers**) and property owners/landlords (**Keepers**), featuring document verification, tenant proof reviews, fraud reporting, and admin moderation.

## Tech Stack
* **Backend:** PHP 8.x (MySQLi with Prepared Statements)
* **Database:** MySQL / MariaDB
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Security:** Cloudflare Turnstile bot protection, server-side file validation, role-based session access control
* **Local Environment:** Windows XAMPP (Apache + MySQL)
